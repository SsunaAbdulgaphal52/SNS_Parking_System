# SNS PARKING SYSTEM

## Project Description
The Spotlight Parking System is a web-based application developed using Django to manage parking operations. It helps attendants manage vehicle owners, vehicles, parking spaces, parking tickets, and payments.

## Technologies Used
- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite

## Installation Instructions

1. Clone the repository.
2. Install the required packages using `pip install -r requirements.txt`.
3. Run `python manage.py migrate`.
4. Run `python manage.py runserver`.
